# 🤝 Вклад в проект

Привет! Это хакатонский клон Wispr Flow. Любые PR — inbound-лицензирование по MIT.

## Быстрый старт

```bash
npm ci          # точные версии из lockfile
npm run dev     # http://localhost:3000 (API на :5000)
npm test        # тесты (node --test, без внешних раннеров)
npm run build   # прод-сборка в dist/
```

## Правила

1. **Тесты обязательны**: новое поведение форматера или API — добавь кейсы в `tests/`.
2. **Без секретов**: ключи только в `.env` (есть `.env.example`), в репо не коммитим.
3. **Стиль кода**: ESM (`import/export`), без лишних зависимостей — сначала подумай,
   нельзя ли на нативных возможностях платформы (WebAudio, Web Speech, node:test).
4. Кириллица в регэкспах: `\b` не работает — используй Unicode-lookaround
   `(?<![\p{L}\p{N}])` / `(?![\p{L}\p{N}])` с флагом `u`.

## Коммиты

Формат свободный, но приветствуются эмодзи-префиксы:
`✨ фича`, `🐛 фикс`, `📝 доки`, `✅ тесты`, `🔧 конфиг`, `⚡️ перф`.
