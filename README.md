# 🏆 Wispr Flow (Hackathon Edition)

Официальный опенсоурс-клон приложения **Wispr Flow**, созданный для участия в хакатоне с главным призoм — **механической клавиатурой за 50 000 рублей**!

---

## 🚀 Основной функционал

1. **Мгновенное распознавание речи**: Интеграция с Web Speech API (Chrome/Edge) для мгновенного ввода на русском (`RU`) и английском (`EN`) языках с переключателем в один клик.
2. **AI Очистка и Форматирование**: Интеграция с Gemini / Emergent API (GPT-4o / Flash) для удаления слов-паразитов («эм», «ну», «как бы»), расстановки пунктуации и форматирования под разные задачи:
   - **Smart Clean** (Чистый текст)
   - **Email** (Деловое письмо)
   - **Список** (Маркированный список)
   - **Чат** (Дружеский диалог)
   - **Код / Tech** (Техническое описание)
3. **Продвинутая аналитика скорости (WPM)**:
   - Скорость ввода в словах в минуту (WPM) в реальном времени.
   - Статистика за сессию и за день.
   - Личный рекорд скорости.
   - Интерактивный счетчик слов и история диктовок.
4. **Кроссплатформенность**: Работает на Windows, Linux и macOS прямо в браузере или в виде десктопного приложения.
5. **Backend на Node.js & Express**: Сохранение статистики сессий, поддержка MongoDB (с автоматическим fallback на локальное хранилище, если MongoDB выключена).

## 🛠️ Пошаговая инструкция: как запустить проект

### 1. Требования
- Установленный **Node.js** (версия 18+ или 20+)
- Установленный **Git**

### 2. Установка зависимостей
Откройте терминал в папке проекта и выполните установку для корня и сервера:
```bash
npm install
cd server && npm install
cd ..
```

### 3. Запуск приложения в режиме разработки
```bash
npm run dev
```
Команда автоматически запустит бэкенд на порту `5000` и фронтенд (Vite) на порту `3000`.
Откройте браузер (рекомендуется **Google Chrome** или **Microsoft Edge**) по адресу:
👉 `http://localhost:3000`
