# 📖 Схема журнала реплики (W-09)

Каждая реплика — одна строка JSON (JSONL, T-01) с полями:

| Поле | Тип | Описание | Критерии |
|---|---|---|---|
| `id` | string | Уникальный идентификатор `u_<hex>_<hex>` | T-13 |
| `v` | number | Версия схемы (сейчас `1`) | T-02 |
| `ts` | string | Момент реплики, **UTC ISO-8601** с таймзоной (`2026-09-05T12:34:56.789Z`) | T-12, M-18 |
| `app` | string | Приложение-цель вставки (`dashboard`, `pill:<window>`, имя окна) | M-02, T-06 |
| `text` | string | Отформатированный текст; **пуст в приватном режиме** | T-10, P-12 |
| `words` | number | Слов в реплике | T-04, AL-10 |
| `wpm` | number | Скорость, слов/мин | AL-02 |
| `durSec` | number | Длительность диктовки, сек | — |
| `mode` | string | Режим стиля: `clean` / `email` / `bullets` / `chat` / `code` | — |
| `lang` | string | Язык распознавания: `ru` / `en` | — |
| `source` | string | Источник постобработки: `local` / `ai` / `webspeech` | S-02, S-08 |
| `latencies` | object | `{ firstHypothesisMs, finalMs, insertMs }` | Q-18 |
| `pasteMethod` | string\|null | `paste` / `clipboard-only` | K-25 |
| `dictHits` | string[] | Сработавшие термины словаря | H-12 |
| `fillersRemoved` | number | Удалено слов-паразитов | — |

## Хранение

- Движок: `localStorage` профиля (в десктопе — данные Electron-приложения), ключ `flow-journal-v1`.
- Ротация: хранится не более **10 000** последних реплик (M-14).
- Перезапуск: журнал переживает перезапуск приложения (M-03).
- Повреждение: при невалидном JSON журнал пересоздаётся пустым (O-11).
- Приватность: включённый режим «без записи текста» пишет все метрики, кроме `text` (P-12, T-10).
- Локальность: журнал никогда не покидает машину (M-16, P-08/P-09).

## Экспорт

- **JSONL**: `История → Экспорт JSONL` — по строке на реплику (M-11).
- **CSV**: `История → Экспорт CSV` — колонки `id,ts,app,words,wpm,durSec,mode,lang,source` (T-08, AL-12).

## Сводка

`История` показывает счётчики за день (T-03/T-04), средний WPM, p50/p95 задержки (T-05, Q-01..Q-06),
распределение по приложениям (T-06) и долю реплик без вызова модели (S-02).
Сводка прогона сервером: `GET /api/summary` (T-15).
