# 🎤 Питч архитектуры — 5 минут (W-12)

## Слайд 0 (30 сек) — «Что это»
1mesto Flow — десктопный голосовой ввод как Wispr Flow: жмёшь хоткей в любом
приложении, говоришь, получаешь вычищенный текст. Полностью рабочая сборка:
установщики для трёх ОС в Release, веб-демо на Pages.

## Слайд 1 (60 сек) — «Архитектура: 4 блока» (W-06)
1. **Захват** (recorder.js): микрофон → 16 кГц моно WAV, свой VAD: обрезка тишины,
   настраиваемый порог, гвард 18 МБ.
2. **Распознавание** — сменный блок за контрактом «аудио → текст»: Web Speech API
   в вебе, whisper.cpp офлайн, Gemini как облачный резерв с фолбэк-цепочкой моделей
   (квота кончилась у одной — берём следующую).
3. **Постобработка** (formatter.js) — сердце проекта, правило вместо LLM (J-09):
   паразиты, самоисправления, числа/даты/время, гомоглифы, словарь пользователя
   **одним union-regex за один проход** (5000 позиций ≈ 3 мс/реплика; до оптимизации
   был 160 секунд — кейс организаторов).
4. **Вставка**: буфер + Ctrl+V в фокус, восстановление буфера без гонки,
   фолбэк на clipboard-only.

## Слайд 2 (60 сек) — «Почему это надёжно»
- 205 автотестов + 8 SSR, eslint 0 warnings, prettier, c8 coverage 94%+, всё в CI.
- Fail-safe: диск полон, занятый порт, 429/404 модели, битые настройки, вторая
  копия, конфликт хоткеев — на каждый случай честное сообщение и запасной путь (O-группа).
- Приватность: локальный путь не обращается в сеть (наши тесты гоняются с закрытой
  сетью), телеметрии нет, ключи не покидают машину, журнал шифро-готов, сервер
  слушает только loopback.

## Слайд 3 (60 сек) — «Что измеряли» (X/Q/S-группа)
- форматтер: 922–7141 ops/s (p50 ≈ 1 мс) — на 2–3 порядка быстрее речи;
- словарь 5000: 146 мс холодный старт, ~3 мс тёплый;
- замены — детерминированы, повтор прогона даёт тот же балл (AB-12).

## Слайд 4 (30 сек) — «Оригинальная фича» (AK)
«Проверка вслух»: после вставки приложение само перечитывает текст системным
голосом — проверить текст не отрываясь от дела. Работает офлайн,
выключается тумблером, покрыта тестами.

## Слайд 5 (30 сек) — «Честный зачёт»
Что сделано кодом, что требует стенда (вставка по ОС, замеры энергии) — показываем
STAND_DEMO.md чеклист. Дорожная карта после хакатона: шифрование журнала, WER-стенд.
