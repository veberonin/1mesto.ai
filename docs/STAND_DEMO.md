# 🎤 Стенд-демо: чеклист (аудио + 3 ОС)

Этот файл — шпаргалка для демонстрации на оценочном стенде.
Задача: за 90 секунд показать «голос → чистый текст» и не облажаться ни на одной ОС.

## ⚡ Сценарий демо (90 секунд)

1. **Герой (10 с).** Открыть приложение. Слоган «Не печатай. Просто говори.» — уже продаёт.
2. **Живая диктовка (30 с).** Нажать пилюлю (или `Alt+Space`). Проговорить, например:
   > «эм ну привет команда жюри это самое наш проект это клон Wispr Flow точка мы сделали мгновенное распознавание речи запятая умную очистку от слов паразитов и аналитику скорости точка кстати голосовая пунктуация тоже работает восклицательный знак»

   Пока говоришь — волна на пилюле прыгает в такт голосу, текст печатается в реальном времени.
3. **Магия форматера (15 с).** Остановить запись. Показать левую панель («сырая диктовка» с «эм… ну…») и правую («Результат Flow»: точки, запятые, заглавные, без паразитов). Бейдж «−N паразитов».
4. **Режимы (15 с).** Переключить на «Email» — текст мгновенно превращается в деловое письмо с подписью. Потом «Список» — в маркированный список.
5. **Куда угодно (10 с).** «Копировать результат» → вставить в блокнот/браузер/мессенджер. «Работает в любом поле ввода».
6. **Аналитика (10 с).** Вкладка «Аналитика»: график WPM, рекорды, сэкономленные минуты против клавиатуры.

## 🛟 Запасной план (если что-то пошло не так)

| Проблема | Решение |
|---|---|
| Микрофон не разрешили | Кнопка **«▶ Демо RU»** — весь пайплайн проигрывается сам, включая волну и WPM |
| Нет интернета на стенде | Локальный форматер работает **полностью офлайн**; с Ollama — даже AI-полировка офлайн |
| Браузер не тот (Firefox/Safari) | Web Speech API есть в Chrome/Edge — открой в них; в остальных покажи демо-режим |
| Сервер недоступен | Приложение полностью живёт на фронтенде: статистика в localStorage, бейдж честно покажет «Локально» |

## 🖥 Особенности ОС

### Windows 10/11
- Браузер: **Chrome** или **Edge** (оба ок).
- Если микрофон молчит: *Параметры → Конфиденциальность и защита → Микрофон → Разрешить классическим приложениям доступ*.
- Запуск: `npm run dev` (Node 18+). Горячие клавиши `Alt+Space` могут перехватываться PowerToys — отключи ихhook или используй клик по пилюле.

### macOS 12+
- Браузер: **Chrome** (Safari **не** поддерживает Web Speech API — не пытайся).
- Первый запуск: система спросит разрешение микрофона для Chrome → «Разрешить».
- Если молчит: *System Settings → Privacy & Security → Microphone → Chrome ✅*.
- Запуск: `npm run dev` (Node 18+, лучше через `nvm install`).

### Linux (X11 / Wayland)
- Браузер: **Chrome/Chromium** (в Firefox Web Speech API требует внешних сервисов — не стабильно).
- Аудио: PulseAudio или PipeWire. Если тишина: `pavucontrol` → вкладка «Запись» → проверить, что Chrome берёт сигнал с правильного источника.
- Wayland: разрешение микрофона запрашивается через xdg-desktop-portal — один раз подтвердить.
