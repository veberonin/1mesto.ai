# 🎬 Сценарий демо-ролика ≤ 3 минут (W-11)

Сними OBS'ом (или Win+G) экран 1920×1080, звук с микрофона. Итог — один take или склейка
из 4 сцен ниже. Файл залей в Release (asset: demo.mp4) и приложи ссылку в README.

## Сцена 1 · «Проблема» (0:00–0:20)
Показываешь печать длинного сообщения руками — медленно, с опечатками.
Голос за кадром: «Печатаю 40 слов в минуту. Говорю — 150. Wispr Flow это понимает.
Я собрал его клон за хакатон — целиком на своём коде».

## Сцена 2 · «Установка за 30 секунд» (0:20–0:50)
Скачиваешь AppImage/exe со страницы Release → запускаешь → иконка в трее.
Голос: «Скачал — установил — работает. Настройки в JSON, автозапуск и глобальный
хоткей — как в оригинале».

## Сцена 3 · «Магия» (0:50–2:10) — главная
1. Открываешь Telegram/Notion → жмёшь Alt+Space → чёрная пилюля.
2. Говоришь сырой текст с паразитами: «ну в общем типа созвонимся с ребятами
   пятого марта в три часа дня и накиньте идей по проекту эм…».
3. Отпускаешь — текст мгновенно вставлен: «Созвонимся с ребятами 5 марта в 15:00
   и накиньте идей по проекту.» — числа, даты, точки сами.
4. Жмёшь Ctrl+Alt+S несколько раз — профиль стиля меняется (email → список → код),
   диктуешь в каждый.
5. Показываешь словарь: «термин42» из файла превращается в настоящий термин.

## Сцена 4 · «Почему мы» (2:10–3:00)
Быстрый монтаж: трей с тремя состояниями, статистика wpm, проверка вслух (AK),
офлайн-режим без сети (выключи Wi-Fi на камеру!), CI зелёный, 200+ тестов.
Финальный кадр: README со скриншотом. Голос: «Всё локально, без телеметрии.
Код и замеры — в репозитории».
