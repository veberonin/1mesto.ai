# Отчёт по уникальности решения (AE-10)

**Проект:** 1mesto Flow (veberonin/1mesto.ai) · клон-исследование Wispr Flow для хакатона.

## AE-06: собственная реализация ключевого шага

Все четыре ключевых шага пайплайна реализованы с нуля в этом репозитории,
без заимствования модулей и кода других участников и открытых аналогов:

| Шаг | Модуль | Что своего |
|---|---|---|
| Захват | `src/lib/recorder.js` | WavCapture: ScriptProcessor → ресемпл в 16 кГц моно, Wav-кодек, обрезка тишины (VAD-порог), буфер ≤900 с |
| Распознавание | Web Speech API + whisper.cpp CLI + Gemini Audio | сменные распознаватели за одним контрактом «аудио → текст» (AA-04), фолбэк-цепочка моделей |
| Постобработка | `src/lib/formatter.js` | собственный RU/EN-форматтер: паразиты, самоисправление, числа/даты/время/телефоны/email/URL, гомоглифы, голосовые команды, ёфикация, словарь одним union-regex с WeakMap-кешем |
| Вставка | `electron/paste.js`, `electron/main.js` | буфер + системный Ctrl/Cmd+V с восстановлением буфера без гонки, фолбэки по ОС |

## AE-01/AE-02: сходство с аналогами

- Каталог открытых аналогов (Whisper-обёртки, диктовки): совпадают только
  используемые **стандартные платформенные API** (Web Speech API, Electron globalShortcut,
  express) — их нельзя «не использовать».
- С другими командами хакатона код не пересекается: стек другой (см. матрицу —
  Rust/Tauri у лидера, Kotlin, C++), архитектура и файлы свои.
- README, сценарии демо, словарь терминов (Казань/Татарстан) — авторские.

## AE-04/AE-05: заимствованные модули

Заимствований модулей нет. Стороннее — только npm-зависимости, перечисленные
в [docs/THIRD-PARTY-NOTICES.md](docs/THIRD-PARTY-NOTICES.md) (Z-07/Z-09).
Веса модели whisper.ggml скачиваются извне с проверкой SHA-256 (A-08), лицензия
весов отделена от лицензии кода (Z-11/Z-12).
